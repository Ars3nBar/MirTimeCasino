# 🎰 MirTimeCasino

**Фирменное GUI-казино для серверов Minecraft (Paper / Purpur 1.21+)** в стилистике проекта **Mir-Time**.

### ✨ Возможности
* Красивое неоново-синее меню ставок с анимацией вращения барабанов и звуковым сопровождением.
* Поддержка экономики через **Vault** и **PlaceholderAPI**.
* Настраиваемые коэффициенты выигрыша, минимальная и максимальная ставки в `config.yml`.
* Встроенная защита от дюпов и закрытия инвентаря во время прокрутки.

### ⌨ Команды и права
* `/casino` — открыть меню казино (`mirtime.casino.use`).
* `/casino reload` — перезагрузить конфигурацию (`mirtime.casino.admin`).

### 📦 Установка
1. Скачайте `MirTimeCasino.jar` из вкладки **Actions** (или **Releases**).
2. Поместите файл в папку `plugins/` вашего сервера (требуется **Vault**).
3. Перезапустите сервер и настройте ставки в `plugins/MirTimeCasino/config.yml`.
